# Тренажёр викторин (Flutter)

Приложение для подготовки к экзаменам по вопросам из Excel. Работает на Android, iOS, в браузере и на Windows.
Вопросы хранятся на устройстве: Excel-файлы загружаются один раз, а не при каждом запуске.

## Что умеет

- **Группы → компетенции → вопросы.** Каждый импортированный Excel-файл становится компетенцией внутри выбранной группы.
- **Редактирование.** Можно создавать, переименовывать и удалять группы и компетенции, добавлять, менять и удалять вопросы. Неправильных ответов может быть сколько угодно.
- **Повторный импорт без дублей.** Если загрузить обновлённый файл ещё раз, добавятся только новые вопросы.
- **Тест** по компетенции или по всей группе: случайные вопросы и варианты, выбор количества, кнопка «Назад», разбор ошибок.
- **Работа над ошибками.** Приложение помнит вопросы, на которые в последний раз ответили неправильно, и может прогнать тест только по ним.
- **История попыток.** Незаконченный тест можно продолжить после перезапуска.
- **Экспорт и импорт базы** в `questions.json`: резервная копия, перенос на другое устройство и встроенные вопросы.

## Формат Excel

Только `.xlsx`. Нужны колонки:

| Вопрос | Правильный ответ | Неправильный ответ 1 | Неправильный ответ 2 | Неправильный ответ 3 |
|---|---|---|---|---|

Также понимаются названия «Текст вопроса», «Верный ответ», «Неверный ответ 1…3» и английские варианты.
Строка заголовков может стоять не первой (над таблицей бывает название документа).
Если названия не распознаны, берутся первые 5 колонок по порядку.

## Встроенные вопросы

Вопросы из `assets/seed/questions.json` загружаются в базу при первом запуске приложения.
Сейчас этот файл пустой. Заполнить его можно двумя способами.

**Скриптом из папки с Excel-файлами.** Подпапки становятся группами, файлы в них — компетенциями:

```
Data/
  Электромонтёры/
    Охрана труда.xlsx
    ПТЭЭП.xlsx
  Сварщики/
    Сварка МП.xlsx
```

```powershell
dart run tool/build_seed.dart C:\EKE\quizmaster\Data
```

**Из самого приложения.** Импортируйте файлы, разложите их по группам, отредактируйте, затем
меню **⋮ → Экспорт базы (JSON)** и сохраните результат как `assets/seed/questions.json`.

После этого пересоберите приложение. При каждом новом `questions.json` установленное приложение добавит
недостающие вопросы. То, что пользователь уже изменил или добавил сам, не затрагивается.

## Запуск

```powershell
flutter pub get
flutter run -d chrome     # в браузере
flutter run -d windows    # на Windows
flutter run               # на подключённом телефоне
```

Сборка APK:

```powershell
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.
iOS собирается только на macOS: `flutter build ios`.

## APK на GitHub

При каждом пуше GitHub Actions прогоняет тесты и собирает APK (вкладка **Actions** → сборка → **Artifacts**).
Сборки из `main` дополнительно публикуются в **Releases**. Последний APK всегда доступен по ссылке
`https://github.com/Nodensss/quizmaster-flutter/releases/latest/download/quizmaster.apk`.

Чтобы новые версии ставились поверх старых без удаления приложения (и без потери базы), APK нужно
подписывать одним и тем же ключом. Создайте ключ один раз:

```powershell
keytool -genkey -v -keystore release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias quizmaster
```

и добавьте в **Settings → Secrets and variables → Actions** три секрета:

- `ANDROID_KEYSTORE_BASE64`: содержимое `release.jks` в base64 (`[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks"))`);
- `ANDROID_KEYSTORE_PASSWORD`: пароль от ключа;
- `ANDROID_KEY_ALIAS`: `quizmaster`.

Без секретов APK подписывается временным ключом. Перед установкой новой версии старую придётся удалить,
поэтому заранее сделайте **Экспорт базы**.

## Структура кода

- `lib/data/`: модели, разбор Excel, формат JSON и хранилище (sembast: файл на устройстве, IndexedDB в браузере);
- `lib/quiz/`: логика теста и сохранение незаконченного теста;
- `lib/ui/`: экраны;
- `tool/build_seed.dart`: сборка встроенных вопросов из папки с Excel-файлами.

Проверка: `flutter analyze` и `flutter test`.
